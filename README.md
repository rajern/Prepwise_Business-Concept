# Prepwise Business Concept

Arbeidsområde for produkt, frontend, backend og infrastruktur for Prepwise.

## Struktur

- `PRODUCT.md` – produktdefinisjon og målgruppe
- `ARCHITECTURE.md` – tekniske prinsipper og systemgrenser
- `ROADMAP.md` – milepæler og retning
- `TASKS.md` – gjennomførbare oppgaver
- `DECISIONS.md` – arkitekturbeslutninger og begrunnelser
- `frontend/` – klientapplikasjon
- `backend/` – API og domene-/forretningslogikk
- `infra/` – drift, deploy og infrastruktur
- `docs/` – øvrig dokumentasjon

## Komme i gang

1. Kopiér `.env.example` til `.env` og fyll inn lokale verdier.
2. Velg frontend- og backend-stack før applikasjonskode opprettes.
3. Dokumenter sentrale valg i `DECISIONS.md`.
